# Hanmore Labs | PaintHouse VR Website

This public repository contains the standalone informational website, support information, and Privacy Policy for Hanmore Labs PaintHouse VR on Meta Quest.

It is **not the game repository**. There are no Unity project files, APKs, proprietary models, signing keys, user data or private release notes here.

- `index.html`: game information
- `privacy.html`: app-specific Privacy Policy, including data deletion
- `support.html`: support and troubleshooting
- `styles.css`: responsive visual design

Site hosting: GitHub Pages on the `main` branch, at the repository root. Site code uses no third-party tracking scripts or external art assets.

Before a future release, update the policy and game features to match the latest verified build. Never add private information or game source to this repository.
